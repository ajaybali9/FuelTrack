# Fuelio 10.9.4 APK feature map → FuelTrack

Source: `com.kajda.fuelio` APKM unpacked to `fuelio-apkm/base.apk` (static strings / class names).

## Mirrored in FuelTrack now
- Dashboard / Home stats
- Fuel log (fill-ups, full/partial, missed)
- Cost log + categories (service, MOT, insurance, parking, …)
- Nearby fuel prices / stations
- Reminders (date + odometer)
- Multi-vehicle
- Fuel grades (E10/E5/diesel/…)
- CSV import + export (Fuelio-compatible sections)
- Settings (currency GBP/INR, units)
- GPS Trip log

## Not mirrored yet
- Android Auto / CarPlay
- Receipt scan
- Widgets
- Cloud backup (Drive/Dropbox)
- Fuel log map of past fill-ups
- Weather on fill-ups
- Premium paywall / Pro drawer cards
